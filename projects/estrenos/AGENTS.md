# Instrucciones locales de Estrenos

Estas instrucciones complementan las de `C:/jumalenin-ecosistema/AGENTS.md` y
`C:/jumalenin-ecosistema/sites/support/AGENTS.md`; no sustituyen sus restricciones.

En tareas del seguimiento de estrenos, antes de diagnosticar un bloqueo o repetir
una consulta fallida, leer `docs/DIAGNOSTICO-Y-RECUPERACION.md`. Contrastar el estado
actual con el historial persistente: la guía documenta un incidente pasado y no
autoriza reabrir informes, reenviar correos ni cambiar la automatización.

Priorizar las instrucciones más recientes del usuario sobre cualquier procedimiento
histórico del README o de la guía. Conservar avances y comprobar el resultado real
de las herramientas antes de declarar inaccesible una fuente o un archivo.
